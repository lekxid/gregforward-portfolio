Versioned delivery

A Git-based deployment workflow for the portfolio, with a focus on validation and recoverability.

GitHub Actions · Git · CI/CD

Project context

The original Azure workflow pulled into a live directory and restarted both the portfolio and shared Caddy proxy. The revised workflow validates the static site without restarting shared services.

Engineering approach

Keep build validation separate from infrastructure changes. Publish only website assets, record the release commit, and verify the public result.

Explore the implementation

The public repository contains the portfolio frontend, a saved reverse proxy configuration, and delivery workflows. It does not contain the complete server-side application.
